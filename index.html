📋 Regras do Bolão
PONTUAÇÃO
🎯 Placar exato 10 pts
✅ Empate certo 7 pts
✅ Acertou o vencedor 5 pts
❌ Errou 0 pts
PRAZO DOS PALPITES

🔒 Os palpites são bloqueados automaticamente no horário exato do apito inicial. Após o bloqueio não é possível alterar ou inserir novos palpites.

PRIVACIDADE

👁️ Os palpites dos outros participantes ficam ocultos até o início do jogo. Após o bloqueio, todos podem ver os palpites de todos.

PALPITE DO CAMPEÃO

🏆 Cada participante escolhe um país para ser o campeão da Copa. Se acertar, ganha 30 pts de bônus. O palpite fica bloqueado no início do 1º jogo.

FASE ELIMINATÓRIA

⚽ Os 32 jogos da fase eliminatória (Fase 32, Oitavas, Quartas, Semifinal e Final) também pontuam com as mesmas regras. Os times de cada jogo são definidos pelo admin conforme os classificados.

ACESSO

🔐 Cada participante cria uma senha no cadastro. A senha é necessária para inserir palpites. Sem ela, só é possível visualizar.
